Choose **SHOOTING LAB** on the title screen. Select A Instant, B Timing or C Assisted; normal generated gameplay; straight/curved road; Range, Accuracy and seed. START / RESTART TEST applies settings. In-run A/B/C switches restart the same seed. CONFIG returns to setup, RETRY repeats it, RESET LAB restores defaults. The diagnostic overlay shows range/distance, ideal timing, last outcome and cooldown.

Touch: swipe anywhere, including Shoot, for movement; tap Shoot to fire once on release. Independent fingers may shoot and move. Keyboard: A/D or arrows, Space/W, S, Enter, Escape. Controls remain Gameplay12: 32 m/s, Closer camera, 84 dp Shoot and 18 dp swipes. Every test starts/restarts with 99 arrows and zero shooting cooldown. Each deliberate tap consumes one arrow; holding never repeats. Pickups add two, capped at 99. Normal health, animal motion and obstacles remain active for a 90-second / 2,880 m run.
